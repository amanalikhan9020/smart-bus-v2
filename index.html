SECURITY & PRIVACY

SmartBus Security

This educational app runs entirely in your browser. Use disposable test accounts; there is no server authentication or live passenger tracking.

01

Account Security

Risk: Unauthorized users may try to access another person's account.

What could be affected: User profile information and saved trips.

Implemented: Passwords are derived with PBKDF2-SHA-256 and an individual random salt using Web Crypto. Incorrect passwords are rejected. Legacy local accounts are migrated without changing their trip identifiers.

02

Passenger Data Privacy

Risk: Passenger counting and location systems may collect sensitive information.

What could be affected: Passenger privacy and location information.

Implemented: User and stored trip text is rendered as text, not executable HTML. Saved trips are separated by local user ID. All occupancy values are simulated; no real passenger data is collected.

Limits and next steps

localStorage is not encrypted. The browser owner can modify accounts, sessions and trips; all guest sessions share the same guest trip list. These controls are a local demonstration, not a server security boundary. A future version needs server-side sessions, access checks and a secure database. We do not use facial recognition.
