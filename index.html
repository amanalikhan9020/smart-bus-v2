SECURITY & PRIVACY

SmartBus Security

SmartBus considers possible security and privacy risks related to user accounts and passenger information.

01

Account Security

Risk: Unauthorized users may try to access another person's account.

What could be affected: User profile information and saved trips.

Solution: Use secure authentication, strong passwords and encrypted password storage.

02

Passenger Data Privacy

Risk: Passenger counting and location systems may collect sensitive information.

What could be affected: Passenger privacy and location information.

Solution: Store only anonymous passenger counts and aggregated data.

Planned Security Improvement

SmartBus plans to use secure authentication and anonymized passenger data. Passenger counting will store only the number of passengers and will not use facial recognition.
