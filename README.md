# SmartBus Astana

Учебный прототип выбора поездки по **симулированной** загруженности автобуса. HTML, CSS и JavaScript; сервер приложения, платное API и физические датчики не нужны.

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте локальный адрес сервера в обычном браузере. Для регистрации с Web Crypto используйте localhost/loopback или HTTPS, а не открытие HTML через `file:`. В облачной среде проверяйте сервер локальными запросами; создание публичного preview не требуется.

Сборка и установка пакетов для запуска сайта не нужны. Файл `.nojekyll` сохраняет публикацию GitHub Pages как статического сайта без обработки Jekyll. Leaflet 1.9.4 хранится локально в `vendor/leaflet`; фоновые тайлы OpenStreetMap загружаются из Интернета. Данные принадлежат origin браузера: смена порта, профиля, протокола или очистка localStorage создаёт отдельное хранилище. Данные переживают перезагрузку страницы и перезапуск сервера при сохранённом origin и профиле.

## Основной сценарий

1. Продолжить как гость или зарегистрироваться/войти.
2. Выбрать маршрут, остановку в списке или на карте и время.
3. Получить прогноз и сравнить варианты отправления: выбранное время, +30 и +60 минут.
4. Выбрать вариант и сохранить именно его.
5. Открыть Saved Trips, перезагрузить страницу и найти поездку; доступны фильтр и удаление.
6. Посмотреть среднюю/максимальную загрузку и диаграмму сохранённых поездок. После добавления и удаления данные пересчитываются.

Варианты сравнения обозначают моменты для расчёта, а не реальное расписание автобусов. Одинаковые прогнозы допустимы. Переход через полночь отмечается как следующий день.

## Карта и изменение времени

Карта связана с выбранным маршрутом и остановкой: щёлкните по пронумерованному маркеру, чтобы выбрать остановку и пересчитать прогноз. Выбор в списке также выделяет соответствующий маркер. Доступны масштабирование и возврат к полному маршруту.

Координаты остановок и линии маршрутов **приблизительные, демонстрационные**: промежуточные точки получены интерполяцией между опорными точками. Это не проверенная геокодировка, официальная трасса CTS или отслеживание автобусов в реальном времени.

Время можно вводить с точностью до минуты, выбирать ползунком или изменять кнопками −15/+15 минут. «Now» устанавливает текущее время Астаны (`Asia/Almaty`). Прогноз и варианты сравнения обновляются сразу. Кнопки меняют показания часов циклически через полночь; календарная дата не выбирается. Существующее сравнение +30/+60 минут отдельно отмечает следующий день при переходе через полночь.

Для подложки используется OpenStreetMap с атрибуцией на карте. API-ключ и backend не нужны. При недоступности тайлов остаются локальная схематичная подложка, линии и маркеры; состояние поясняет сообщение карты. Leaflet распространяется по BSD-2-Clause: лицензия и проверенный SHA-512 исходного npm-пакета указаны в `vendor/leaflet/LICENSE` и `vendor/leaflet/PROVENANCE.txt`.

## Ограничения и незавершённые пункты

- Карта показывает приблизительные демонстрационные позиции остановок и линии; официальные координаты/трассы CTS не подтверждены. Онлайн-подложка требует доступа к OpenStreetMap, а при отказе используется локальная схема.
- Прогноз задаётся правилами спроса; это не машинное обучение, не live CTS и не гарантия времени прибытия.
- Аккаунты и поездки локальные, синхронизации и серверной авторизации нет. Получение хеша пароля через PBKDF2 не шифрует localStorage и не защищает от владельца браузера.
- Обычные старые пароли автоматически мигрируют в PBKDF2 с сохранением ID и поездок. Для старого пустого/пробельного пароля требуется явная замена через локальную форму восстановления. Это исправление слабой старой записи в текущем браузере, не защищённый удалённый сброс пароля.
- Безопасный вывод текста защищает от исполнения HTML в отображаемых значениях; он не превращает статический прототип в защищённый серверный продукт.
- Результаты двух реальных пользователей вне команды и два улучшения именно по их feedback ещё не предоставлены. Автоматические тесты и исправления по аудиту их не заменяют.
